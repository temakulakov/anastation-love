## 🔧 Кастомизация

### Добавление Данных Timeline

Отредактируйте `/utils/constants.ts`:

```typescript
export const MOCK_TIMELINE_DATA = [
  {
    id: 1,
    date: '14.02.2024',
    title: 'Первая встреча',
    description: 'Описание события',
    photos: [
      'https://example.com/photo1.jpg',
      'https://example.com/photo2.jpg',
    ],
  },
  // Добавьте еще события
];
```

### Изменение Пароля

В `/utils/constants.ts`:

```typescript
export const VALID_PASSWORDS = [
  'принцесса',
  'принцессочка',
  'ваш_пароль',
];
```

### Добавление Музыки

Поместите MP3 файл сюда: `/public/audio/background.mp3`
