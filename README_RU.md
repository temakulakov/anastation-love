# 💕 Анастасия - Наша История Любви

Невероятно красивый и анимированный сайт, посвященный нашей особенной истории. Создан с использованием **Next.js**, **Framer Motion** и **SCSS**.

## ✨ Особенности

- 🔐 **Авторизация** - Вход по волшебному паролю (производные от "принцесса")
- ⏳ **Индикатор загрузки** - С милым единорогом и фразами про загрузку любви
- 📅 **Timeline** - Интерактивный таймлайн с памятными датами
- 📸 **Галерея фото** - До 4 фото на карточку, просмотр на полный экран
- 🎵 **Музыка** - Кнопка для переключения фоновой музыки
- 💕 **Милый дизайн** - Розовая цветовая гамма с декоративными элементами:
  - Сердечки 💕
  - Черепа (милый стиль) 💀
  - Капибары 🐹
  - Единороги 🦄
- 📱 **Адаптивность** - Полная поддержка мобильных устройств
- 🖤 **Чистый код** - Разделение UI и бизнес-логики, SCSS модули

## 🚀 Быстрый Старт

### Требования
- Node.js 18+
- npm или yarn

### Установка и Запуск

```bash
# Установить зависимости
npm install

# Запустить dev сервер
npm run dev

# Открыть в браузере
# http://localhost:3000
```

## 🎨 Структура Проекта

```
/components       - React компоненты
  - AuthPage.tsx        - Страница авторизации
  - LoadingPage.tsx     - Экран загрузки с индикатором
  - TimelinePage.tsx    - Главная страница с таймлайном
  - TimelineCard.tsx    - Карточка события на таймлайне
  - MusicToggle.tsx     - Кнопка включения/выключения музыки
  - DecorationElements.tsx - Декоративные элементы

/styles           - SCSS стили
  - globals.scss        - Глобальные стили
  - components/         - Стили компонентов (SCSS модули)

/utils            - Утилиты и хуки
  - constants.ts        - Константы (пароли, фразы, данные)
  - useBackgroundMusic.ts - Хук для управления музыкой

/public           - Статические файлы
  - audio/              - Аудиофайлы (place your background.mp3 here)

/app              - Next.js App Router
```

## 🔑 Варианты Пароля

Авторизация работает с любым из этих вариантов (+ как минимум 8 символов):
- `принцесса`
- `принцессочка`
- `принцесск`
- `принце`

## 📝 Кастомизация

### Добавление Фото
Измените `MOCK_TIMELINE_DATA` в `/utils/constants.ts`:

```typescript
{
  id: 1,
  date: '14.02.2024',
  title: 'Название события',
  description: 'Краткое описание',
  photos: [
    'URL фото 1',
    'URL фото 2',
    'URL фото 3',
    'URL фото 4'
  ],
}
```

### Добавление Музыки
Поместите ваш `background.mp3` файл в `/public/audio/`

### Изменение Цветов
Отредактируйте переменные SCSS в `/styles/globals.scss`:

```scss
$primary-pink: #ff69b4;
$dark-pink: #ff1493;
$light-pink: #ffb6d9;
```

### Изменение Фраз Загрузки
Отредактируйте массив `LOADING_PHRASES` в `/utils/constants.ts`
